# Карта ВОЛС — прототип MVP

Статический кликабельный прототип публичной части реестра ВОЛС. Он использует только вымышленные демонстрационные данные и не подключён к базе данных.

## Запуск

Откройте `index.html` в браузере или разместите содержимое папки на любом статическом HTTPS-хостинге. Для корректной работы интерактивной подложки требуется интернет-доступ к OpenStreetMap и CDN Leaflet.

## Важно для рабочего запуска

Прототип не реализует авторизацию и серверную защиту. Перед внесением реальных инженерных данных необходимы Supabase/PostgreSQL/PostGIS, RLS для всех закрытых таблиц и отдельные публичные представления, не содержащие точную геометрию или закрытые контакты.

Следующий этап: перенести интерфейс в React + TypeScript + Vite после установки Node.js и подключить серверный слой с миграциями и политиками доступа.
